지금 쓰는 코드는 [`../fall_detection/`](../fall_detection/)에 있다. 여기 있는 파일은 변천 과정을 남기려고 보관한 것이며, **결과를 그대로 믿으면 안 된다.**

| 파일 | 내용 |
|---|---|
| `stat_test.py`, `stat_test3.py` | 통계 방법 3종(Robust Z, Moving Z, IQR) |
| `ml_dl_test.py`, `ml_dl-test1.py` | 통계 3종 + 로지스틱 회귀·LightGBM·오토인코더 |
| `Lo.py`, `Li.py`, `au.py` | 로지스틱 회귀, LightGBM, 오토인코더를 하나씩 |

## 알려진 문제

- **라벨**: 경로에 `fall`·`dusme`가 있으면 낙상으로 본다. 낙상 폴더 20개 중 이 규칙에 걸리는 것은 902, 917 두 개뿐이라 낙상의 약 90%가 정상으로 라벨된다. 올바른 기준은 폴더 앞 세 자리 코드(9xx = 낙상)다
- **센서**: 시행마다 부위별 센서 파일 6개가 있는데 전부 별도 샘플로 쓴다. 안경이면 머리 센서(`340506`)만 써야 한다
- **열 선택**(`Lo`, `Li`, `au`, `stat_test`): `iloc[:, :6]`이 `Counter, Temperature, VelInc…`를 가져온다. 가속도·자이로가 아니다
- **분할**: 파일 단위 무작위 분할이라 같은 사람이 학습과 테스트에 함께 들어간다
- **기준값·임계값**: 통계 방법의 중앙값·평균·사분위수를 테스트셋에서 계산하고, 임계값도 테스트 라벨로 고른다
- **추론 시간**: 판정 1회가 아니라 평가 함수나 빈 구간을 잰다
- **Moving Z**(`stat_test3`, `ml_dl-test1`): 이동 창이 시간축이 아니라 무작위로 섞인 테스트 행 사이를 움직인다
- `stat_test3.py`는 앞쪽 파일 500개만 읽는다
